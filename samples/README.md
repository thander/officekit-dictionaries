# Шаблоны презентаций OfficeKit

30 презентаций PowerPoint на русском языке. В каждом файле шесть слайдов формата 16:9 с редактируемым текстом и подсказками по заполнению. В шаблонах с таблицами и диаграммами можно менять данные.

Откройте ссылку на нужный шаблон и скачайте файл через кнопку **Download raw file**. Сохраните свою копию и замените текст в квадратных скобках, фотографии и примерные значения своими материалами.
