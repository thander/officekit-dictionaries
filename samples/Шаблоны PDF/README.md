# Шаблоны PDF

Одностраничные бланки A4. Поля и флажки можно заполнять в PDF-редакторе с поддержкой форм. Для печати подойдут и чистые бланки. Подписи в акте и расписке проставляются вручную.

| Шаблон | Для чего |
| --- | --- |
| [Акт приёма-передачи имущества](Акт%20приёма-передачи%20имущества.pdf) | Записать состав, состояние и комплектность переданного имущества. |
| [Расписка о получении денег](Расписка%20о%20получении%20денег.pdf) | Зафиксировать стороны, сумму и основание платежа. |
| [План переезда](План%20переезда.pdf) | Собрать адреса, контакты и задачи на день переезда. |
| [Чек-лист поездки](Чек-лист%20поездки.pdf) | Проверить документы и вещи перед выездом. |
| [План личных расходов](План%20личных%20расходов.pdf) | Сверить план по категориям с фактическими тратами. Итоги вводятся вручную. |
